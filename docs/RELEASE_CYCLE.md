# RECOIL X release cycle

Every major lettered milestone (A, B, C, ...) introduces the major feature/gameplay direction.

| Stage | Purpose |
|---|---|
| .1 | Expand milestone content |
| .2 | Bug fixes, optimization and stability |
| .3 | Gameplay, controls, UI and audio polish |
| .4 | Expanded and improved models |
| .5 | Small content update |

Keep existing gameplay and progression, fix urgent defects at any stage, require regression checks and successful deployment before calling a release complete. A.2 remains in development; new optional content is normally deferred to .5 or the next milestone.
