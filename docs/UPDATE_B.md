# Update B — Ocean Breeze: development preview 1

This branch is not deployed. Production remains A.5. The lobby is based on the inspected Coastal Frontier reference with an original low-cost vector coastal scene, not the original raster illustration. It uses actual existing game navigation, currency balances, local/account profile and online friends, not fake data. Classic menu remains reachable. Eight themes, 20 milestones, six new deterministic arena layouts, and legacy maps are included. The server's existing 500-XP levels are authoritative for signed-in accounts; offline saves stay separate. Rewards are derived from verified lifetime XP and do not enter random boxes, trading or cash economy. Equip choices and avatar are local preferences. Existing season dates and awards are deliberately preserved; Season 1 is already active in A.5's schedule. The Aqua Tech panel exposes the ocean level-track items. Party is the existing friends/party implementation; no new voice system or fabricated friend records.

Review limitations: actual screenshot fidelity, translations, full mobile/TV visual testing, cross-device equipped cosmetics, 3D curved terrain, water simulation and server-backed competitive versions of the new maps remain to verify or extend. New maps currently support offline and existing peer voting; server authoritative ranked modes retain their existing layouts. No production deployment until approval. Preview-only standalone lobby in preview/update-b-lobby.html; run locally with server dependencies installed (Node 24, npm install --prefix server, node server/server.mjs, http://127.0.0.1:8787). Use a separate development database; do not point preview at production. Installers planned in follow-up preview commit.
